# 语音服务开机自启配置指南 (Ubuntu 20.04)

本文档说明 RK3588 上 SmartCockpit 语音服务的 systemd 开机自启配置。当前服务文件随项目部署在 `voice-assistant-server/scripts/deploy/voice-assistant.service`。

## 1. 创建 Service 配置文件

在 RK3588 的终端执行以下命令，创建新的 systemd 配置文件：

```bash
sudo nano /etc/systemd/system/voice-assistant.service
```

## 2. 贴入配置内容

在编辑器中粘贴以下内容。当前 RK3588 部署路径为 `/opt/jw`，默认启动 Qwen3.5-0.8B 文本和视觉服务：

```ini
[Unit]
Description=SmartCockpit Voice Assistant
Wants=network-online.target NetworkManager-wait-online.service
After=network-online.target NetworkManager-wait-online.service sound.target

[Service]
Type=oneshot
User=ztl
Group=ztl
WorkingDirectory=/opt/jw/voice-assistant-server/scripts/deploy
Environment=HOME=/home/ztl
Environment=USER=ztl

# 默认启动 Qwen3.5-0.8B 文本+视觉；不跟随实时日志
ExecStart=/opt/jw/voice-assistant-server/scripts/deploy/voice-assistant.sh start --no-follow

# 停止命令
ExecStop=/opt/jw/voice-assistant-server/scripts/deploy/voice-assistant.sh stop

RemainAfterExit=yes
TimeoutStartSec=240
TimeoutStopSec=90

[Install]
WantedBy=multi-user.target
```

粘贴完毕后，保存并退出（在 nano 中按 `Ctrl+O` 回车保存，`Ctrl+X` 退出）。

## 3. 加载并启用服务

依次执行以下命令，让系统识别并启用该服务：

```bash
# 1. 重新加载 systemd 让它识别新服务
sudo systemctl daemon-reload

# 2. 设置为开机自动启动
sudo systemctl enable voice-assistant.service

# 3. 立即启动服务测试一下
sudo systemctl start voice-assistant.service
```

## 4. 日常管理指令

设置完成后，你可以使用以下命令来管理语音服务：

- **查看当前运行状态：**
  ```bash
  sudo systemctl status voice-assistant.service
  ```
- **查看历史运行日志（按 `Ctrl+C` 退出）：**
  ```bash
  journalctl -u voice-assistant.service -f
  ```
- **停止服务：**
  ```bash
  sudo systemctl stop voice-assistant.service
  ```
- **重启服务：**
  ```bash
  sudo systemctl restart voice-assistant.service
  ```

## 5. 使用旧模型

开机自启默认使用 Qwen3.5。手动启动旧模型时，在 `start` 后明确指定模型参数，例如：

```bash
/opt/jw/voice-assistant-server/scripts/deploy/voice-assistant.sh start qwen3-4b --no-follow
```

支持的旧模型参数包括 `3b`、`7b`、`qwen3-1.7b` 和 `qwen3-4b`。旧模型按纯文本模式运行，不加载 Qwen3.5 视觉编码器。
