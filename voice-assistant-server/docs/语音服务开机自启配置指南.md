# 语音服务开机自启配置指南 (Ubuntu 20.04)

本文档将指导你如何通过 `systemd` 将语音服务配置为系统级服务，实现开机自启、崩溃自动重启，并实现服务的后台静默运行。

## 1. 创建 Service 配置文件

在 RK3588 的终端执行以下命令，创建新的 systemd 配置文件：

```bash
sudo nano /etc/systemd/system/voice-server.service
```

## 2. 贴入配置内容

在编辑器中粘贴以下内容（注意：`User=` 和 `Group=` 请确保是你日常登录的系统用户名，例如 `ztl`，而运行路径统一在 `/home/jw` 目录下）：

```ini
[Unit]
Description=智能车载语音助手服务
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=ztl
Group=ztl
WorkingDirectory=/home/jw/voice-assistant-server/scripts/rk3588

# 启动命令（如果不需要视觉，可以在末尾加上 --no-vision）
ExecStart=/bin/bash /home/jw/voice-assistant-server/scripts/rk3588/start.sh qwen3-4b

# 停止命令
ExecStop=/bin/bash /home/jw/voice-assistant-server/scripts/rk3588/stop.sh

# 进程如果意外崩溃，自动在 10 秒后重启
Restart=always
RestartSec=10

# 禁用超时，避免模型加载太慢被 systemd 强杀
TimeoutStartSec=0
TimeoutStopSec=60

[Install]
WantedBy=multi-user.target
```

粘贴完毕后，保存并退出（在 nano 中按 `Ctrl+O` 回车保存，`Ctrl+X` 退出）。

## 3. 加载并启用服务

依次执行以下命令，让系统识别并启用该服务：

```bash
# 1. 重新加载 systemd 让它识别新服务
sudo systemctl daemon-reload

# 2. 设置为开机自动启动
sudo systemctl enable voice-server.service

# 3. 立即启动服务测试一下
sudo systemctl start voice-server.service
```

## 4. 日常管理指令

设置完成后，你可以使用以下命令来管理语音服务：

- **查看当前运行状态：**
  ```bash
  sudo systemctl status voice-server
  ```
- **查看历史运行日志（按 `Ctrl+C` 退出）：**
  ```bash
  journalctl -u voice-server -f
  ```
- **停止服务：**
  ```bash
  sudo systemctl stop voice-server
  ```
- **重启服务：**
  ```bash
  sudo systemctl restart voice-server
  ```
