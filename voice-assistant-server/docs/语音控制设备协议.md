# 车辆设备控制协议

> 语音控制系统通过 HTTP POST 与车辆设备控制服务通信，所有数据均为 JSON 格式。

---

## 一、控制指令（POST /command）

### 请求

- **URL**: `http://{设备服务地址}:9000/command`
- **方法**: POST
- **请求头**: `Content-Type: application/json`
- **超时**: 1 秒

#### 请求体
```json
{
  "type": "command",
  "target": "设备标识",
  "action": "动作标识",
  "params": {}
}
```

### target（设备标识）
| 值 | 设备 |
|----|------|
| `vis_cam` | 白光摄像机 |
| `ir_cam` | 热像仪 |
| `gimbal` | 转台 |
| `laser` | 激光器 |
| `tracker` | 跟踪器 |
| `mast` | 桅杆 |
| `all` | 当前车型中支持该动作的“所有设备”逻辑组（例如 Z1 上电组不含跟踪器和桅杆） |

### action（动作标识）
| action | 含义 | 适用设备 |
|--------|------|----------|
| `enable` | 开机 | vis_cam, ir_cam, gimbal, laser, mast |
| `disable` | 关机 | vis_cam, ir_cam, gimbal, laser, mast |
| `view_large` | 大视场 | vis_cam, ir_cam |
| `view_small` | 小视场 | vis_cam, ir_cam |
| `zoom_in` | 放大 | vis_cam |
| `zoom_out` | 缩小 | vis_cam |
| `focus_auto` | 自动对焦 | vis_cam |
| `focus_in` | 调焦加 | vis_cam |
| `focus_out` | 调焦减 | vis_cam |
| `cross_show` | 十字丝开 | vis_cam, ir_cam |
| `cross_hide` | 十字丝关 | vis_cam, ir_cam |
| `brightness_up` | 亮度加 | vis_cam |
| `brightness_down` | 亮度减 | vis_cam |
| `enhance_on` | 增强开 | vis_cam, ir_cam |
| `enhance_off` | 增强关 | vis_cam, ir_cam |
| `fog_on` | 透雾开 | vis_cam |
| `fog_off` | 透雾关 | vis_cam |

| `digital_zoom` | 数字变倍 | vis_cam, ir_cam |
| `polarity_black` | 黑热 | ir_cam |
| `polarity_white` | 白热 | ir_cam |
| `contrast_up` | 对比度加 | ir_cam |
| `contrast_down` | 对比度减 | ir_cam |
| `auto` | 自动模式 | ir_cam |
| `gamma_correction` | 图像校正 | ir_cam |
| `scene_correction` | 场景校正 | ir_cam |
| `zero_return` | 归零 | gimbal |
| `zero_drift` | 零漂校正 | gimbal |
| `scan_circle` | 周扫 | gimbal |

| `scan_stop` | 扫描停止 | gimbal |
| `detect_on` | 识别开 | tracker |
| `detect_off` | 识别关 | tracker |
| `track_on` | 跟踪开 | tracker |
| `track_off` | 跟踪关 | tracker |
| `park_work` | 驻车展开 | mast |
| `drive_work` | 行车展开 | mast |
| `onekey_work` | 一键展开 | mast |
| `end_work` | 撤收 | mast |
| `stop_work` | 停止 | mast |
| `mast_raise` | 举升 | mast |
| `mast_lower` | 下降 | mast |
| `single_level` | 单次调平 | mast |

| `recon_start` | 开始侦察 | mast |

### params（可选参数）
| 参数 | 适用 action | 说明 |
|------|-------------|------|
| `zoom_level` | digital_zoom | 倍数，如 `"1"` `"2"` `"4"` |
| `direction` | scan_circle | `"cw"` 顺时针 / `"ccw"` 逆时针 |
| `count` | scan_circle | 圈数或次数 |

### 响应

设备服务返回 JSON：
```json
{
  "success": true,
  "state": "on",
  "message": ""
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `success` | bool | 是否执行成功 |
| `state` | string | 执行后状态，如 `"on"` `"off"` `"ok"` |
| `message` | string | 额外信息：空=正常；`"already_on"`=已开机；`"already_off"`=已关机；其他=错误原因 |

### 示例

**请求**：
```json
POST /command
{
  "type": "command",
  "target": "vis_cam",
  "action": "enable"
}
```

**响应**：
```json
{ "success": true, "state": "on", "message": "" }
```

## 二、状态查询（POST /status）

### 请求

- **URL**: `http://{设备服务地址}:9000/status`
- **方法**: POST
- **请求头**: `Content-Type: application/json`
- **超时**: 1 秒

#### 请求体
不指定设备则查全部：
```json
{}
```

指定设备：
```json
{ "target": "vis_cam" }
```

### 响应

```json
{
  "devices": {
    "vis_cam": { "power": "on", "cross": "off", "enhance": "off", "fog": "off" },
    "ir_cam":  { "power": "off", "cross": "off", "enhance": "off" },
    "gimbal":  { "power": "on" },
    "laser":   { "power": "off" },
    "tracker": {}
  }
}
```

### 状态键含义
| 状态键 | 中文 |
|--------|------|
| `power` | 电源 |
| `cross` | 十字丝 |
| `enhance` | 增强 |
| `fog` | 透雾 |
| `detect` | 识别 |
| `track` | 跟踪 |
| `recon` | 侦察 |

### 状态值含义
| 值 | 中文 |
|----|------|
| `on` | 开 |
| `off` | 关 |
| `open` | 开 |
| `closed` | 关 |
| `unknown` | 未知 |

### 示例

**请求**：
```json
POST /status
{ "target": "vis_cam" }
```

**响应**：
```json
{ "devices": { "vis_cam": { "power": "on", "cross": "off" } } }
```

## 三、POST 返回值机制

语音控制系统通过 **`requests.post`** 发送请求，**`response.json()`** 解析响应体：

```python
resp = requests.post(cmd_url, data=payload, headers={"Content-Type": "application/json"}, timeout=1.0)
if resp.status_code == 200:
    body = resp.json()        # ← 解析 JSON 响应体
    success = body["success"] # ← 读取 success 字段
    state   = body["state"]   # ← 读取 state 字段
    message = body["message"] # ← 读取 message 字段
```

**简言之：POST 的返回值就是 HTTP 响应体里的 JSON 数据**，调用方从中取出 `success`/`state`/`message` 判断执行结果。

## 四、本地模拟服务

如需本地测试，启动模拟服务端：

```bash
python scripts/mock_vehicle_server.py [port]   # 默认 9000
```

监听两个端点：
- `POST /command` — 执行控制指令
- `POST /status` — 查询设备状态

初始状态全部为 OFF。
