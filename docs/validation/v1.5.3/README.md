# v1.5.3 源码版本

发布日期：2026-10-30。此版本保存语音服务源码、五个提示音及板端核验记录。

## 修改内容

- 语音启动状态只播报“语音服务运行正常。”“语音服务运行异常。”“语音服务已恢复。”。
- 车辆状态单独播报“车辆控制服务未连接。”“车辆控制服务已恢复。”，不影响语音状态。
- 多个语音故障合并播报一次，语音和车辆提示串行播放，详细原因保留在日志中。
- 按网页、唤醒、混合模式检查实际服务响应；唤醒客户端报告采集心跳、连接及识别和播报组件就绪状态。
- 删除六个旧的逐项故障提示音。

音量由开发板独立的系统启动配置管理，本版本源码不设置音量。
保留现场配置、麦克风输入设置、模型和车辆控制服务。

## 验证

186 项语音回归通过，407 个受控运行文件与板端一致；范围沿用 v1.5.2 运行文件清单。
静音属于有效采集数据，启动检查不能证明模拟麦克风已接好或实际拾音效果正常。
本次没有进行整机重启验收，系统音量恢复已通过启动项执行验证。
当前开发板车辆控制入口未监听，按设计独立报告“车辆控制服务未连接。”；本次未修改或重启该服务。
